discorddol.tools

SSOT verb list for discorddol: plain functions, JSON-able in, JSON-able out.

Deliberately agnostic about how it is reached. This module knows nothing about MCP, HTTP, argparse or any agent host; a wrapper references e.g. discorddol.tools:messages and gets a clean JSON-ready value back. __main__.py builds the CLI off the same list (DISPATCH_FUNCS), so a new verb becomes available on every surface at once.

discorddol.tools.DISPATCH_FUNCS = [<function guilds>, <function channels>, <function messages>, <function transcript>, <function export_channel>, <function find_deleted_channels>, <function recover_attachments>, <function post_message>]

The SSOT list every surface dispatches over. Add a verb here, get it everywhere.

discorddol.tools.find_deleted_channels(guild: str, *, token: str | None = None, cache_dir: str | None = None) → dict[source]

Find channel ids cached on this machine that no longer exist in a server.

Discord cannot undelete a channel, but the desktop client cached its attachments. This is how you find the id of a deleted channel, so you can recover those attachments with recover-attachments and locate the channel in a data export.

discorddol.tools.guilds(*, token: str | None = None) → list[dict][source]

List the Discord servers the bot has been added to.

Run this first: if it returns an empty list, the bot exists but has not been invited to any server yet.
